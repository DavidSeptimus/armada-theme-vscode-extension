# Change Log

## [Unreleased]

v2.0.0 - 2026-11-19

### Changed

- Optimized for VS Code's modern UI: the shell, floating surfaces, activity bar and pill tabs follow the Islands look of Armada for JetBrains IDEs
- Colors that were off Armada's palette now follow the JetBrains theme: search and occurrence highlights, git decorations, warnings, symbol icons, inputs and greys
- Colors VS Code used to derive itself are now set by the theme

### Added

- `custom.css`, optional CSS that rounds the side bar and outlines the selected tabs, for use with a custom CSS loader
